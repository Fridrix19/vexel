# Vexel

Оплата зарубежных сервисов рублями: долларовая виртуальная карта и каталог из 105 сервисов, оплата по QR через СБП.

Бренд — «Vexel OS», ретро-терминал: тёмный экран CRT по умолчанию (`#0E0D0A`), янтарь `#FFB000`, розовый `#FF5E7E`, бирюзовый `#5CE1E6`; светлый «режим печати» — переключателем в строке состояния. Шрифты: Press Start 2P (заголовки, пиксельные), Fira Code (весь текст). Прямые углы, окна с полосатым заголовком и кнопками `[_][□][×]`, кнопки в квадратных скобках, развёртка CRT поверх экрана. Знак — пиксельная V с курсором (`build/brand/logo.svg`), иллюстрация — монитор с командной строкой (`build/brand/hero-art.svg`).

Оболочка: строка меню как в старой ОС (часы, подчёркнутые первые буквы), строка пути `vexel@pay:~/страница$`, подвал — баннер из блочных символов и строка состояния. Первые экраны: главная — терминал с журналом загрузки, окна card.exe и sysmon; каталог — двухпанельный файловый менеджер; вопросы — страница `man`; как устроено — мастер установки; помощь — окно ошибки; контакты — `ping`; тарифы — `cat tariffs.txt`; карта — `vexel card --info`; раздел — `cd && ls`; сервис — `vexel info`. Популярное — таблица процессов, разделы — папки на рабочем столе. Кабинет — панель задач внизу экрана, админка — строка функциональных клавиш внизу (Alt+1…Alt+0) и сводка в духе `top`.

## Структура

```
_proto/          собранный сайт (статика): главная, каталог, разделы, 105 страниц сервисов, карта, как это устроено,
                 помощь, контакты, вопросы, тарифы, вход, личный кабинет
src/base/        общая база: токены и компоненты (base.css, lib.css), шапка, подвал и мобильное меню, common.js
src/pages/       страницы: <page>.html|js|css, данные разделов section-<id>.json
build/           сборка build.py, бренд brand/, icon-lum.json (яркость логотипов сервисов)
source-site/     данные каталога: логотипы сервисов (assets/), список (search.js), тарифы (payment-flow.v2.js)
web/             бэкенд и админка: Nuxt 4 + Nitro, PostgreSQL — см. web/README.md
render.yaml      стенд на Render + Neon
```

## Сборка

```bash
python3 build/build.py            # все страницы, кроме сервисов
python3 build/build.py all        # всё, включая 105 страниц сервисов
cd web && npm ci && npm run build # сервер отдаёт _proto/ и API /api/*
```

## Отдельный стенд

У Vexel своя база, свои админы и пользователи. Для стенда: новый проект в Neon, новый Web Service в Render из этого репозитория (настройки — в `render.yaml`), свои значения `NUXT_DATABASE_URL`, `NUXT_SECRET`, почты и `NUXT_PUBLIC_SITE_URL`. Первый вход в админку `/admin` — admin / admin, затем смена пароля.

## Запуск на своём компьютере (Mac)

Нужны Node.js 20+ и [Postgres.app](https://postgresapp.com) (Initialize → Start). Затем:

```
cd web && bash start-local.sh
```

Скрипт сам создаст базу `vexel`, поставит зависимости, соберёт проект, применит миграции и запустит сервер: сайт — http://localhost:3002, админка — http://localhost:3002/admin (admin / admin, затем смена пароля). Код регистрации показывается на экране, письма — в логе.

## Бета на Vercel

Репозиторий готов к выкладке на Vercel как бета-стенд: сайт, кабинет и админка в одном проекте, база — Neon (PostgreSQL).

1. vercel.com → Add New → Project → импорт `Fridrix19/vexel`. Настройки сборки менять не нужно — они в `vercel.json`.
2. В проекте: Storage → Create Database → Neon, регион Frankfurt (eu-central-1) → подключить к проекту. Переменные `DATABASE_URL` и `DATABASE_URL_UNPOOLED` появятся сами.
3. Deployments → Redeploy. При сборке накатываются миграции и создаются тестовые входы.

Входы на бете:
- кабинет: `test@gmail.com` / `test` (подсказка есть на странице входа);
- админка: `/admin`, `admin` / `admin`, смена пароля на бете отключена.

Что работает иначе, чем на своём сервере:
- файлы загружаются до 4 МБ за раз (лимит Vercel), фото сжимаются в браузере автоматически;
- курс ЦБ (если включён автокурс) обновляется раз в сутки по расписанию Vercel;
- коды подтверждения почты показываются на экране — настоящие письма не уходят.

Необязательно: `NUXT_SECRET` (иначе ключ берётся из адреса базы) и `CRON_SECRET` (защита расписания).
Хранить данные реальных клиентов на бете нельзя: Vercel и Neon за рубежом, а по 152-ФЗ персональные данные россиян хранятся в России.
